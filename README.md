# credit-card-hub

8 張信用卡的權益自動巡檢與刷卡決策網站。純靜態站，部署在 GitHub Pages，手帳風。

## 這是什麼

- 每天 09:00（台灣時間）由排程用瀏覽器核對各銀行官網最新信用卡權益，有變動就自動更新本站並重新部署
- 網頁上可以：店家搜尋（打「星巴克」直接告訴你刷哪張）、情境試算（哪張卡最划算、要不要拆單）、各加碼池額度進度與記帳、維護卡片清單與銀行帳戶等級
- 讀寫分離：`data/user_state.json` 是雲端基準（卡片、等級），`data/benefits_db.json` 只由排程寫入（權益知識庫），兩邊不會互相覆蓋

## 檔案結構

```
index.html                  靜態 SPA（店家搜尋／試算／額度記帳／卡片管理）
data/
  user_state.json           卡片、銀行等級、記帳的初始資料（雲端基準）
  benefits_db.json          各卡加碼池權益（排程自動更新）
  merchants.json            店家關鍵字→適用加碼池對照表
```

## 使用方式（免設定）

直接打開網站就能用，不需要填任何 token：
- 權益資料每天 09:00 由排程自動更新
- 你在網站上的記帳、卡片修改都存在這台裝置的瀏覽器裡（localStorage）
- 加卡、刪卡或改銀行帳戶等級後，跟助理說一聲，助理會幫你同步到雲端，隔天排程才會用新設定巡檢

## 本地預覽

```bash
cd credit-card-hub && python3 -m http.server 8000
# 打開 http://localhost:8000
```

## 排程

- 主排程每天 09:00：讀 `user_state.json` → 瀏覽器巡檢銀行官網 → 比對更新 `benefits_db.json` → 有變動才 push
- 守衛每天 10:00：檢查主排程是否正常完成，異常時代查
- 台新納入正常巡檢；國泰 CUBE 產品權益頁解析成本較高，活動頁正常巡檢
